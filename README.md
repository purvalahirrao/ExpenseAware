# ExpenseAware 💰

A personal finance and expense tracking web application designed to help users manage their money more mindfully.

## Features

- Dashboard showing income, expenses, and net balance
- Add and manage financial transactions
- Monthly income vs. expenses chart
- Category-wise expense chart
- Expense breakdown by category
- Monthly financial history
- Budget and savings goals
- SQLite database for storing financial records

## Technologies Used

- Python
- SQLite
- HTML
- CSS
- JavaScript (if used in the implementation)

## Getting Started

### Prerequisites

- Python 3 installed

### Run the Application

1. Clone or download this repository.
2. Open the project folder in the terminal.
3. Run:

   `python app.py`

4. Open your browser and visit:

   `http://127.0.0.1:5000`

## Project Purpose

ExpenseAware was developed as a practical portfolio project to explore web application development, financial data management, and visual reporting.
